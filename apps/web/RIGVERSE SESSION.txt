● RIGVERSE — Port Already in Use Fix

  The error EADDRINUSE ::3000 means something is already running on port 3000.
  Here's how to fix it:

  ---

  Method 1: Kill the Existing Process (Recommended)

  Option A: Using Command Prompt ( easiest on Windows)

  1. Find what's using port 3000:
  netstat -ano | findstr :3000
  2. Note the PID (the last column number)
  3. Kill it:
  taskkill /F /PID <PID-number>
     (Replace <PID-number> with the actual number from step 2)

  Option B: Using PowerShell

  # Find the process
  Get-NetTCPConnection -LocalPort 3000 | Select-Object State, OwningProcess

  # Kill it (replace <PID> with the process ID)
  Stop-Process -Id <PID> -Force

  ---

  Method 2: Use a Different Port

  If you can't/kill the existing process, run on a different port:

  # Start Next.js on port 3001 instead
  PORT=3001 npm run dev

  Or permanently in .env.local:
  PORT=3001

  Then access the app at http://localhost:3001.

  ---

  Method 3: Check for Existing Dev Server

  If you already have npm run dev running in another terminal, just use that
  one. The npm start command is for production mode only.

  Correct usage:
  - npm run dev — Development mode with hot reload (port 3000)
  - npm run build → npm start — Production mode

  ---

  Method 4: Wait & Retry

  Sometimes the port is released quickly. Wait 10-15 seconds and try again:

  # Wait 15 seconds, then
  npm run dev

  ---

  Quick Fix Sequence (Method 1)

  Run these commands in order:

  netstat -ano | findstr :3000
  taskkill /F /PID 12345
  npm run dev

  (Where 12345 is the PID you saw from netstat)

  ---

  After Fix

  Once the port is free, run:

  npm run dev

  The RIGVERSE Live Build Tracker should launch at http://localhost:3000 with
  all features working:
  - Three-stage pipeline (Forge → Studio → Showcase)
  - Auto-refresh toggle
  - Live price aggregation
  - Compatibility checking
  - Scene controls
  - Room themes
  - Accessory catalog

  Choose Method 1 first — it's the most direct fix for Windows.
